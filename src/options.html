Repo Foyer

The extension reads your repositories and your commit activity with a GitHub token. The token stays in this browser and is only sent to api.github.com.

Getting a token

Create a classic token with the repo scope. It sees all your repositories, including private ones and the ones in your organizations.

If you use the GitHub CLI, you can also run gh auth token | pbcopy and paste the result here.

Visit history

To find the repos you use the most, the extension counts how often you open each one in this browser.
